OBJECTIF

Toutes les interfaces de l'Agent Support doivent être orientées vers
l'efficacité opérationnelle.

L'Agent traite plusieurs dizaines de tickets par jour.

Chaque clic inutile doit être supprimé.

Toutes les interfaces doivent être rapides.

Toutes les informations importantes doivent être visibles immédiatement.

=====================================================================
REGLE ABSOLUE
=====================================================================

Toutes les interfaces doivent permettre à l'Agent Support de traiter
un ticket avec un minimum de clics.

Les informations critiques doivent toujours être visibles.

Les actions doivent toujours être sécurisées par les permissions
retournées par le backend.

Le frontend ne doit jamais afficher une action que l'Agent n'est pas
autorisé à exécuter.
