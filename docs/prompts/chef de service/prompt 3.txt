=====================================================================

OBJECTIF

Toutes les interfaces du Chef de Service doivent être conçues pour lui
permettre de piloter son service.

Le Chef ne travaille pas comme un Agent.

Il supervise.

Il décide.

Il répartit.

Il contrôle.

Toutes les interfaces doivent être orientées Management.

=====================================================================
ORGANISATION GENERALE
=====================================================================

Le Chef dispose de deux espaces totalement indépendants.

=====================================================================
REGLES UX
=====================================================================

Le Chef ne doit jamais naviguer dans plusieurs écrans pour prendre une
décision simple.

Les indicateurs importants doivent toujours être visibles.

Les couleurs doivent permettre d'identifier immédiatement les urgences.

Les tableaux doivent supporter :

Tri

Filtres

Colonnes personnalisables

Pagination

Recherche instantanée

Export

=====================================================================
REGLE ABSOLUE
=====================================================================

Toutes les interfaces doivent être conçues pour aider le Chef de
Service à piloter efficacement son équipe.

Le frontend ne doit jamais afficher une action que le backend refuse.

Toutes les actions critiques doivent être confirmées, journalisées,
auditables et sécurisées.
