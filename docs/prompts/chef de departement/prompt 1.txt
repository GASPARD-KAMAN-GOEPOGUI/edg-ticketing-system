==========================================================
CHEF DE DEPARTEMENT
PARTIE 1
IDENTITE - MISSION - RESPONSABILITES
==========================================================

OBJECTIF

Le Chef de Département est responsable de plusieurs services.

Il supervise les Chefs de Service.

Il garantit la bonne performance de tout son département.

Il n'intervient dans un ticket que lorsque cela est nécessaire.

Son rôle est principalement stratégique.

==========================================================
IDENTITE
==========================================================

Nom officiel

Chef de Département

Description

Le Chef de Département dirige plusieurs services.

Exemple

Département Exploitation

• Service Support

• Service Maintenance

Le Chef supervise les deux services.

Il ne remplace jamais les Chefs de Service.

==========================================================
MISSION
==========================================================

Garantir le bon fonctionnement du département.

Superviser les Chefs de Service.

Contrôler les performances.

Suivre les indicateurs.

Traiter les situations complexes.

Décider lors des escalades importantes.

Accompagner les responsables de service.

==========================================================
OBJECTIFS
==========================================================

Améliorer les performances.

Réduire les escalades.

Garantir les SLA.

Répartir correctement les ressources.

Améliorer la satisfaction utilisateur.

==========================================================
EXEMPLE
==========================================================

Le Département Exploitation possède :

Service Support

Service Maintenance

Le tableau de bord indique :

Support

95 tickets.

Maintenance

18 tickets.

Le Chef constate un déséquilibre.

Il décide :

Répartir plusieurs tickets vers Maintenance.

Les statistiques sont recalculées.

Les Chefs de Service concernés sont notifiés.

Toutes les décisions sont enregistrées dans l'audit.

==========================================================
REGLE ABSOLUE
==========================================================

Le Chef de Département pilote plusieurs services.

Il ne remplace pas les Chefs de Service.

Il intervient uniquement lorsque les décisions dépassent le niveau d'un service.

Toutes ses décisions doivent être :

• justifiées

• auditables

• sécurisées

• historisées
