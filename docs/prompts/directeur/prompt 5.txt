==========================================================
DIRECTION DSI
PARTIE 5
CAS METIERS
==========================================================

OBJECTIF

Cette partie décrit les situations réelles auxquelles la Direction DSI
peut être confrontée.

L'application doit appliquer exactement ces comportements.

La Direction DSI intervient uniquement lorsque la décision dépasse le
niveau d'un Chef de Département.

==========================================================
CAS N°1
UN INCIDENT MAJEUR EST DECLARE
==========================================================

Situation

Une panne affecte plusieurs directions de l'entreprise.

Le système détecte plusieurs tickets liés.

Le Chef de Département demande l'intervention de la Direction DSI.

La Direction DSI :

• consulte le dossier complet

• confirme qu'il s'agit d'un incident majeur

• désigne un département pilote

• mobilise les autres départements concernés

• suit l'évolution jusqu'au rétablissement

Toutes les décisions sont enregistrées dans l'audit.

==========================================================
CAS N°2
CYBERATTAQUE
==========================================================

Situation

Une activité suspecte est détectée.

Le système déclenche une alerte critique.

La Direction DSI :

• consulte les informations disponibles

• active la cellule de crise

• mobilise les départements concernés

• suit les actions en temps réel

• informe la Direction Générale si nécessaire

Chaque décision est historisée.

==========================================================
CAS N°3
PLUSIEURS DEPARTEMENTS SONT BLOQUES
==========================================================

Situation

Un système critique devient indisponible.

Plusieurs départements ne peuvent plus travailler.

La Direction DSI :

• identifie les départements concernés

• définit les priorités

• coordonne les interventions

• suit les délais de rétablissement

• communique régulièrement l'avancement

==========================================================
CAS N°4
PLUSIEURS SLA SONT DEPASSES
==========================================================

Le tableau de bord affiche plusieurs dépassements de SLA.

La Direction DSI :

• analyse les causes

• identifie les départements concernés

• demande un plan d'action

• décide si des ressources supplémentaires sont nécessaires

Le suivi continue jusqu'au retour à une situation normale.

==========================================================
CAS N°5
UN DEPARTEMENT EST SURCHARGE
==========================================================

Le tableau de bord indique :

Département A : 850 tickets

Département B : 220 tickets

Département C : 180 tickets

La Direction DSI :

• analyse les raisons de cette surcharge

• réunit les Chefs de Département concernés

• décide d'une réorganisation si nécessaire

• suit l'impact des décisions

==========================================================
CAS N°6
UN INCIDENT RESTE BLOQUE
==========================================================

Un incident majeur reste ouvert depuis plusieurs jours.

La Direction DSI :

• consulte l'historique

• analyse les blocages

• demande des explications

• valide un nouveau plan d'action

==========================================================
CAS N°7
PLUSIEURS INCIDENTS SIMILAIRES
==========================================================

Le système détecte une forte augmentation de tickets identiques.

La Direction DSI :

• vérifie s'il s'agit d'une même cause

• demande la création d'un incident majeur si nécessaire

• coordonne les actions communes

==========================================================
CAS N°8
ESCALADE STRATEGIQUE
==========================================================

Un Chef de Département transmet un dossier.

La Direction DSI :

• consulte toutes les informations

• vérifie les décisions déjà prises

• valide ou modifie la stratégie

• communique sa décision

==========================================================
CAS N°9
COMMUNICATION DE CRISE
==========================================================

Une panne importante touche les utilisateurs.

La Direction DSI :

• rédige une communication officielle

• choisit les destinataires

• publie le message

• met à jour la communication à chaque étape importante

Toutes les communications sont historisées.

==========================================================
CAS N°10
FIN D'UN INCIDENT MAJEUR
==========================================================

Les services sont rétablis.

La Direction DSI :

• vérifie que tous les impacts sont résolus

• valide la clôture de l'incident majeur

• demande un rapport de retour d'expérience

• suit les actions d'amélioration décidées

==========================================================
CAS N°11
REVUE HEBDOMADAIRE
==========================================================

Chaque semaine, la Direction DSI consulte :

• les performances des départements

• les performances des services

• les SLA

• les incidents majeurs

• les escalades

• les réouvertures

• la satisfaction utilisateur

Elle identifie les axes d'amélioration.

==========================================================
CAS N°12
REVUE MENSUELLE
==========================================================

Chaque mois, la Direction DSI analyse :

• les tendances

• les volumes de tickets

• les performances

• les coûts opérationnels (si disponibles)

• les besoins en ressources

Elle prépare les décisions stratégiques du mois suivant.

==========================================================
CAS N°13
CONTINUITE D'ACTIVITE
==========================================================

Une panne importante empêche un département de fonctionner.

La Direction DSI :

• active le plan de continuité prévu par l'organisation

• répartit temporairement certaines activités

• suit le retour progressif à la normale

==========================================================
CAS N°14
REUNION DE PILOTAGE
==========================================================

La Direction DSI organise une réunion avec les Chefs de Département.

L'application permet d'afficher :

• les indicateurs

• les incidents majeurs

• les SLA

• les performances

• les décisions en attente

Ces informations servent de base à la réunion.

==========================================================
CAS N°15
PREPARATION D'UN RAPPORT POUR LA DIRECTION GENERALE
==========================================================

La Direction Générale demande un bilan.

La Direction DSI génère un rapport contenant :

• les indicateurs principaux

• les incidents majeurs

• les SLA

• les performances des départements

• les actions d'amélioration

Le rapport est exporté au format demandé.

==========================================================
BONNES PRATIQUES
==========================================================

Toujours analyser avant de décider.

Toujours coordonner les départements.

Toujours communiquer lors d'une crise.

Toujours documenter les décisions.

Toujours suivre les indicateurs.

Toujours préparer un retour d'expérience après un incident majeur.

==========================================================
ERREURS A EVITER
==========================================================

Ne jamais traiter directement les tickets courants.

Ne jamais contourner un Chef de Département sans justification.

Ne jamais modifier l'historique.

Ne jamais supprimer une trace d'audit.

Ne jamais prendre une décision sans justification.

==========================================================
REGLE ABSOLUE
==========================================================

La Direction DSI représente le niveau stratégique de la plateforme.

Elle garantit la continuité des services.

Elle coordonne les départements.

Elle arbitre les situations critiques.

Elle pilote la performance globale de la DSI.

Toutes les décisions doivent être :

• justifiées

• enregistrées

• auditables

• sécurisées

La Direction DSI intervient uniquement lorsque la décision dépasse le
niveau d'un département.
